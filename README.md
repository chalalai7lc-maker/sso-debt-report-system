# SSO Debt Report System
**ระบบประมวลผลรายงานหนี้ค้างชำระสถานประกอบการ สำนักงานประกันสังคม**

ระบบเว็บแอปพลิเคชันสำหรับนำเข้าข้อมูลรายงานหนี้ค้างชำระ (รหัสรายงาน `CN200090-1` / `CN5R013`), รวมยอดหนี้ตามเลขอ้างอิง (`เลขที่บัญชี` + `สาขา`), สรุปช่วงงวดเดือนค้างชำระเป็นภาษาไทย (แบบแจกแจงทุกช่วงต่อเนื่อง), เชื่อมโยงข้อมูลชื่อสถานประกอบการจริงและที่อยู่ (ตำบล, อำเภอ, จังหวัด, รหัสไปรษณีย์) จากฐานข้อมูล `SSO_WCF_Report_System`, และส่งออกไฟล์รายงานในรูปแบบ Excel พร้อมใช้งานทันที

---

## คุณสมบัติเด่น (Features)
1. **นำเข้าข้อมูลรายงานได้อย่างยืดหยุ่น**:
   - รองรับไฟล์ Excel (`.xlsx`, `.xls`) และ `.csv`
   - กรองและตัดหัวรายงานซ้ำจากการแบ่งหน้า (Page Breaks) อัตโนมัติ
   - ลากและวางไฟล์ (Drag & Drop) หรือเลือกประมวลผลไฟล์ที่มีอยู่แล้วในโฟลเดอร์ `Input/`
2. **ประมวลผลและจัดกลุ่มตามเลขอ้างอิง (`เลขที่บัญชี` + `สาขา`)**:
   - 1 เลขอ้างอิง รองรับการค้างชำระได้หลายงวด
   - สรุปงวดเดือนค้างชำระตามข้อกำหนดแบบ B (เช่น `เมษายน 2569 - พฤษภาคม 2569, กรกฎาคม 2569`)
   - คำนวณยอดหนี้ไม่รวมเงินเพิ่ม (ผลรวมของหนี้ประเมิน + หนี้จริง)
   - สรุปยอดเงินเพิ่มและยอดค้างชำระรวมทั้งสิ้น
3. **เชื่อมโยงข้อมูล Master Data สถานประกอบการ (`DATA-EMP-WCF.xlsx`)**:
   - จัดเก็บไฟล์ Master Data อยู่ในโฟลเดอร์โครงการ [`data/DATA-EMP-WCF.xlsx`](file:///c:/Users/Administrator/Documents/Second%20Brain/Projects/SSO_Debt_Report_System/data/DATA-EMP-WCF.xlsx)
   - ตรวจจับการเปลี่ยนแปลงของไฟล์บนดิสก์อัตโนมัติ (Auto-reload on file modification)
   - มีระบบอัปเดตไฟล์ Master Data ชุดใหม่ผ่านหน้า Web Dashboard หรือกดปุ่มรีโหลดข้อมูลได้ทันที
   - ดึงข้อมูล: ชื่อสถานประกอบการ (จริง), ที่อยู่, ตำบล, อำเภอ, จังหวัด, รหัสไปรษณีย์ โดยจับคู่ตรงตามคีย์ `เลขสปก.` (`เลขที่บัญชี;เลขที่สาขา`)
   - รายการที่ไม่พบคู่ตรงจะปล่อยว่างไว้เพื่อให้เจ้าหน้าที่ตรวจสอบด้วยตนเอง พร้อมคงชื่อเดิมจากรายงานหนี้ไว้ในคอลัมน์อ้างอิง
4. **ส่งออกไฟล์ Excel มาตรฐานระดับมืออาชีพ**:
   - ตกแต่งหัวตารางด้วยโทนสี Deep Navy Blue สวยงาม
   - ฟอร์แมตตัวเลขการเงินพร้อมเครื่องหมายจุลภาคและทศนิยม 2 ตำแหน่ง (`#,##0.00`)
   - ปรับความกว้างคอลัมน์อัตโนมัติ (Auto-fit Column Widths) เพื่อไม่ให้ตัวเลขขึ้น `###`
   - ตรึงแนวหัวตาราง (Freeze Panes) สำหรับการเลื่อนดูข้อมูลขนาดใหญ่
5. **หน้าจอ Web Dashboard ทันสมัย**:
   - สรุปตัวชี้วัด KPI การเงินแบบ Real-time
   - ตารางพรีวิวผลลัพธ์พร้อมระบบค้นหาด่วน (Live Search) ตามชื่อ, เลขบัญชี, สาขา, หรืออำเภอ/จังหวัด
   - ดาวน์โหลดไฟล์ผลลัพธ์ด้วยการคลิกเพียงครั้งเดียว

## วิธีการใช้งาน (Getting Started)

### วิธีที่ 1: รันผ่าน `run.bat` (แนะนำ)
ดับเบิลคลิกที่ไฟล์ `run.bat` ระบบจะตรวจสอบสภาพแวดล้อม Python เริ่มต้นเซิร์ฟเวอร์ และเปิดเว็บเบราว์เซอร์ไปยัง `http://localhost:8001/` ให้โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Command Prompt / Terminal
```bash
python app.py
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:8001/`
