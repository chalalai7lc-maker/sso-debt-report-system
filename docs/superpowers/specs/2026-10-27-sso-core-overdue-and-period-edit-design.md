# การออกแบบระบบตรวจสอบงวดค้างชำระจริงจาก SSO CORE และแก้ไขงวดค้างชำระ (SSO Debt Report System)

**วันที่:** 2026-10-27
**โปรเจค:** `projects/SSO_Debt_Report_System`

## 1. วัตถุประสงค์ (Purpose)
1. เพิ่มทางเลือกให้ผู้ใช้งานสามารถตรวจสอบงวดค้างชำระจริงจากระบบ **SSO CORE** (`https://appssocore.sso.go.th`) ในหน้ารายงานหนี้ โดยอ้างอิงลอจิกจากโปรเจค `SSO_M33_Overdue_System` (`SSOHybridClient` และ `overdue_calculator`)
2. ผู้ใช้สามารถเลือกได้ว่าจะตรวจสอบกับ SSO CORE หรือไม่:
   - **หากไม่กดตรวจสอบ**: ยึดข้อมูลงวดค้างจากไฟล์รายงานหนี้ Excel เป็นหลักในการส่งออก Excel และพิมพ์หนังสือเตือน/เชิญพบ
   - **หากกดตรวจสอบ SSO CORE**: อ้างอิงงวดเดือนค้างชำระจริงจาก SSO CORE (คำนวณงวดที่ยังไม่ชำระและกรองตาม Timeline เปิด/ปิดกิจการ) แทนที่งวดค้างของแต่ละบัญชี และสามารถสลับกลับไปใช้งวดจาก Excel ต้นฉบับได้ตลอดเวลา
   - กรณีตรวจสอบแล้วพบว่าสถานประกอบการ **ชำระครบแล้ว (เหลือ 0 งวด)**: แสดงในตารางหน้ารายงานหนี้พร้อมสถานะ `"ชำระครบแล้ว (0 งวด)"` และในหน้าพิมพ์หนังสือจะกรองเฉพาะรายที่มียอดค้าง `>= 1 งวด` เป็นค่าเริ่มต้น เพื่อไม่ให้พิมพ์หนังสือซ้ำซ้อนไปหานายจ้างที่ชำระแล้ว
3. เพิ่มฟีเจอร์ **แก้ไขงวดค้างชำระรายบัญชี** ได้ทั้งในหน้า "รายงานหนี้" และหน้า "พิมพ์หนังสือ" โดยซิงค์ข้อมูลถึงกันทั้งหมด รวมถึงการส่งออกไฟล์ Excel (`.xlsx`) และการพิมพ์หนังสือเตือน/เชิญพบ (`.docx` / `.pdf`)

## 2. สถาปัตยกรรมและองค์ประกอบ (Architecture & Components)

### 2.1 โมดูลเชื่อมต่อ SSO CORE (`overdue_calculator.py` & `sso_client.py`)
- คัดลอกและปรับใช้ `overdue_calculator.py` และ `sso_client.py` จาก `SSO_M33_Overdue_System` มายัง `SSO_Debt_Report_System`
- รองรับการอ่านค่า `SSO_USERNAME`, `SSO_PASSWORD` จาก `.env` (ทั้งในโฟลเดอร์โปรเจคและโฟลเดอร์ `SSO_M33_Overdue_System` หากยังไม่มีในโปรเจค) และแชร์/แคช Token ใน `.sso_token_cache.json`
- ฟังก์ชันหลัก: `await sso_client.check_account_overdue(company_no, branch_code, start_year, as_of_date)`

### 2.2 โครงสร้างข้อมูลใน `debt_processor.py`
- เพิ่มการ 정규화 (Normalize) งวดดิบให้อยู่ในรูปแบบ `MM/YYYY` ที่เรียงลำดับตามปี พ.ศ. และเดือน
- เพิ่มฟิลด์ในแต่ละแถวของ `preview_data`:
  - `งวดดิบ`: `List[str]` งวดที่ใช้อ้างอิงปัจจุบัน
  - `งวดดิบ_ต้นฉบับ`: `List[str]` งวดจากไฟล์ Excel เดิมสำหรับอ้างอิงหรือรีเซ็ต
  - `งวดดิบ_sso`: `Optional[List[str]]` งวดที่ได้จากการตรวจสอบ SSO CORE (หากตรวจสอบแล้ว)
  - `แหล่งข้อมูลงวด`: `"Excel"` | `"SSO CORE"` | `"แก้ไขเอง"`
  - `สถานะตรวจสอบ_SSO`: ข้อความสถานะจาก SSO CORE (เช่น `"ยังไม่ตรวจสอบ"`, `"ค้างชำระ"`, `"ชำระครบแล้ว (0 งวด)"`, `"ไม่พบบัญชี"`)
- เพิ่มเมธอด ` DebtReportProcessor.build_export_from_records(records, output_dir, custom_filename)` เพื่อสร้างไฟล์ Excel ส่งออกใหม่เมื่อมีการอัปเดตงวดจาก SSO CORE หรือจากการแก้ไขของผู้ใช้

### 2.3 API Endpoints ใน `app.py`
1. `POST /api/sso-core/check`
   - รับ `accounts: List[{"acc": str, "branch": str}]`, `start_year: int = 2568`, `as_of_date: Optional[str] = None`
   - เรียก `sso_client.check_account_overdue` สำหรับแต่ละบัญชี และส่งคืนผลลัพธ์รายบัญชี (`overdue_periods`, `overdue_count`, `formatted_periods_b`, `company_status`, `process_status`, `latest_paid_period`, `timeline_summary`)
2. `POST /api/records/re-export`
   - รับ `records: List[Dict[str, Any]]`, `source_filename: Optional[str]`
   - คำนวณ `จำนวนงวดค้าง` และ `งวดเดือนค้างชำระ` (แบบ B) จาก `งวดดิบ` ล่าสุด สร้างไฟล์ Excel ในโฟลเดอร์ `Output/` และส่งคืน `output_filename` พร้อมสถิติสรุปใหม่

### 2.4 ส่วนติดต่อผู้ใช้ (Frontend: `index.html`, `app.js`, `letters.js`, `style.css`)
1. **แถบเครื่องมือตรวจสอบ SSO CORE (ในหน้ารายงานหนี้)**:
   - ปุ่ม **"🔍 ตรวจสอบงวดค้าง SSO CORE"** พร้อมช่องระบุปี พ.ศ. เริ่มต้นตรวจสอบ (ค่าเริ่มต้น `2568`)
   - ปุ่มสลับแหล่งข้อมูล **"ใช้ข้อมูล SSO CORE"** / **"ใช้ข้อมูล Excel ต้นฉบับ"** (เมื่อตรวจสอบแล้ว)
   - แถบแสดงความคืบหน้าขณะตรวจสอบรายบัญชี (แบ่ง Batch ทีละชุดเพื่อให้เห็นความคืบหน้าจริงและสามารถยกเลิกกลางคันได้)
2. **การแสดงผลในตาราง (หน้ารายงานหนี้ & หน้าพิมพ์หนังสือ)**:
   - แสดงป้ายแหล่งข้อมูลงวด (`Excel`, `SSO CORE`, `แก้ไขเอง`)
   - หาก `จำนวนงวดค้าง == 0` แสดงป้ายสถานะสีเขียว `"ชำระครบแล้ว (0 งวด)"`
   - ปุ่ม **"✏️ แก้ไขงวด"** ในทุกแถวของทั้งสองตาราง
   - ในหน้าพิมพ์หนังสือ ตั้งค่าเริ่มต้นให้กรองเฉพาะรายการที่ `จำนวนงวดค้าง >= 1` (โดยผู้ใช้ยังสามารถปรับช่อง "จำนวนงวดตั้งแต่" เป็น `0` ได้หากต้องการดูทั้งหมด)
3. **หน้าต่างแก้ไขงวดค้างชำระ (Edit Periods Modal)**:
   - แสดงข้อมูลบัญชี/สาขา และชื่อสถานประกอบการ
   - แสดงรายการงวดค้างปัจจุบันแบบป้าย (Tag chips) กด `×` เพื่อลบรายงวดได้
   - ช่องเพิ่มงวดใหม่ (เลือกเดือน + ปี พ.ศ. หรือพิมพ์ `MM/YYYY` เช่น `01/2569, 02/2569` หรือช่วง `01/2569-03/2569`)
   - ปุ่มลัด: **"คืนค่าตามไฟล์ Excel"** และ **"คืนค่าตาม SSO CORE"** (ถ้าเคยตรวจแล้ว)
   - เมื่อกดบันทึก: อัปเดต `งวดดิบ`, `จำนวนงวดค้าง`, `งวดเดือนค้างชำระ`, แจ้งเตือนหน้าพิมพ์หนังสือ (`debt:updated`), และสั่งสร้างไฟล์ Excel ส่งออกฉบับอัปเดตอัตโนมัติ
